# L'atelier Forge³

Ton atelier pour construire ton outil avec l'IA, **sans rien installer sur ton
ordinateur**. Tout se passe dans ton navigateur.

## Ouvrir ton atelier (une seule fois)

1. **Copie l'atelier sur ton compte GitHub** :
   [**Créer mon atelier**](https://github.com/new?template_name=atelier-forge3&template_owner=KreaCity)
   Donne-lui un nom (par exemple `mon-outil`), choisis **Private**, puis
   **Create repository**.
2. Sur la page de ton nouveau dépôt, clique sur le bouton vert **Code**, onglet
   **Codespaces**, puis **Create codespace on main**.
3. Patiente une à deux minutes : ton atelier se prépare tout seul.

Utilise **Chrome** ou **Edge** : c'est là que tout marche le mieux.

## Démarrer avec Claude

1. **La première fois**, dans le terminal en bas, tape `connexion` puis Entrée,
   et suis les 3 gestes affichés (un lien, « Autoriser », un code à coller).
   Tu te connectes avec **ton** compte Claude (abonnement Pro).
2. Ensuite, tape `claude` puis Entrée.
3. Dis à Claude ce que tu veux construire. Par exemple :
   « Lance l'application et montre-la moi. »

## Les trois règles de l'atelier

- **Demande à Claude de sauvegarder** après chaque étape qui marche
  (« sauvegarde mon travail »).
- **Ferme l'onglet quand tu as fini** : l'atelier se met en pause tout seul après
  30 minutes, et ton quota gratuit est préservé.
- **Ne clique jamais sur « Rebuild »** : ça te déconnecte de Claude.
